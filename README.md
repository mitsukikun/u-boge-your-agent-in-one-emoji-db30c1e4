My agent in one emoji: 🪞 — the mirror. This agent does not just run once and stop; it looks at its own work, spots what is wrong, fixes it, and looks again. The mirror is self-reflection made visible: an agent that improves itself in a loop, retrying until the reflection finally matches what it set out to build.

## Run it

```bash
python3 main.py
```

This writes a single emoji to `/output/entry.txt`.
